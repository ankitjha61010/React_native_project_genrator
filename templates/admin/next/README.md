# {{DISPLAY_NAME}} – Admin Panel

Web admin panel for **{{DISPLAY_NAME}}**, generated by [rn-architecture-generator](https://www.npmjs.com/package/rn-architecture-generator).
Stack: **Next.js (App Router) + Tailwind CSS**, axios. It talks to the generated backend's REST API.

## Requirements

- Node.js ≥ 22.13 and npm
- The generated backend running (default `http://localhost:3000/api/v1`)

## Quick start

```bash
npm install
npm run dev          # http://localhost:5173
```

Sign in with an account whose role is **ADMIN**. The backend's seed script creates one from
`SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` in `backend/.env` (`npm run db:seed` in the backend).
Change that password before going live.

## Configuration – `.env.local`

| Variable | Meaning |
|---|---|
| `NEXT_PUBLIC_API_BASE_URL` | Backend API base URL (generated: `{{API_BASE_URL}}`) |
| `NEXT_PUBLIC_APP_NAME` | Name shown in the sidebar and the browser tab |
| `NEXT_PUBLIC_API_ENCRYPTION_ENABLED` | `true` when the backend encrypts request / response bodies |
| `NEXT_PUBLIC_API_ENCRYPTION_KEY` / `NEXT_PUBLIC_API_ENCRYPTION_IV` | Only with encryption – must equal the backend's `API_ENCRYPTION_KEY` / `API_ENCRYPTION_IV` |

The backend must allow this origin: add `http://localhost:5173` (and your production admin URL) to
`CORS_ORIGINS` in `backend/.env`.

## Pages

| Page | What it does | Backend routes |
|---|---|---|
| Dashboard | User and broadcast overview | `GET /users`, `GET /notifications/broadcasts` |
| User Management | List, search, edit, delete users; change a user's avatar | `GET/PATCH/DELETE /users/:id`, `POST /users/:id/avatar` |
| Broadcast Notifications | Send a push notification to all users, history | `POST /notifications/broadcast`, `GET/DELETE /notifications/broadcasts` |
| Legal & Policies | Terms & Conditions / Privacy Policy links and pages shown in the app | `GET/PUT /legal` |
{{#if PAYMENTS}}
| Payments | Products, entitlements, payments, refunds, stats | `/payments/admin/*` |
{{/if}}
{{#if OTA}}
| OTA Releases | Publish / roll back over-the-air JavaScript bundles | `GET/POST /ota/releases`, `POST /ota/releases/:id/rollback` |
{{/if}}

The code for each page is in `src/app/`; API calls go through `src/services/api.ts`
(adds the `Authorization: Bearer` token, signs out on `401`).

## Authentication

`POST /auth/login` with email + password. Users whose role is not `ADMIN` are rejected. The token is kept in
`localStorage` (`admin_token`, `admin_user`).

## Production

```bash
npm run build
npm start            # http://localhost:5173
```

Deploy: A Node.js host that runs `next start` (or any platform that supports Next.js). Set the `NEXT_PUBLIC_*` variables in the host's environment **before** `npm run build` – they are inlined at build time.
